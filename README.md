🚚 Featured project: KurirApp

A multi-tenant courier platform built for Indonesia: IDR currency, Xendit payments, and UU PDP (data protection law) compliance in mind.

Component	Tech
🛠️ Backend	NestJS (modular monolith), PostgreSQL + PostGIS, Redis, Socket.IO
📱 Driver app	Flutter + Riverpod (native, for background GPS tracking)
🌐 Customer web	React
🧑‍💼 Admin panel	React + Vite

Engineering highlights

🔐 Shared-schema multi-tenancy with FORCE Row-Level Security and WITH CHECK policies
💰 Append-only financial ledgers using BigInt
🔄 Refresh token rotation with reuse detection, with separate JWT configs for admin and mobile
🎟️ Invitation-code-based driver onboarding
📞 In-app calls via ZegoCloud
🌿 Phase-gated delivery with feature/tahap-N-* branches
